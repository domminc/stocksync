# 라벨 프린터 연결 (XP-DT427B · 50×30mm)

## 구조
```
브라우저(StockSync 라벨 화면) ──TSPL 명령──▶ 출력 프로그램(매장 PC, 127.0.0.1:9101) ──▶ 프린터(USB 드라이버 또는 LAN 9100)
```
- 사이트는 인터넷 서버에 있어 매장 프린터에 직접 닿을 수 없으므로, 프린터가 연결된 PC에서 아주 작은 중계 프로그램(`public/print-agent/agent.mjs`)이 돈다.
- 브라우저가 프린터 명령(TSPL)을 만든다. 가격·상품명은 화면 글꼴로 그려 이미지(BITMAP)로 보내므로 프린터에 한글 글꼴이 없어도 된다. **바코드는 프린터 내장 기능(BARCODE)** 으로 그려 203dpi 에서 선이 정확히 찍힌다.
- 중계 프로그램은 이 PC 안에서만 열리고(127.0.0.1) `https://jejubaseball.com` 의 요청만 받는다. LAN 프린터는 사내망 IP(10.x · 172.16~31.x · 192.168.x)만 허용한다.

## 라벨 내용
기본은 **가격 + 바코드** (상품명은 사이트에서 스캔해 확인). 라벨 화면의 "라벨에 넣을 내용"에서 `상품명 + 가격` / `바코드만` 으로 바꿀 수 있고 선택은 브라우저에 기억된다. 가격은 상품의 **판매가**이므로 상품 등록·CSV 의 `판매가`를 채워 두어야 한다 (비어 있으면 가격 줄은 비워 둔다).

## 바코드 종류
기본 **Code 128** (숫자·영문 모두, 스캐너 호환성이 가장 넓음). EAN-13 도 선택 가능. 같은 번호가 어느 종류로 찍혀도 스캔 결과는 같은 숫자라 재고 처리는 동일하다.

## 설치 (매장 PC · 윈도우, 한 번만)
`public/print-agent/README.txt` 참고. 요약: 프린터 드라이버 설치 → 라벨 화면의 "출력 프로그램 설치 파일"(`install-windows.bat`) 실행 → 라벨 화면 "프린터 설정"에서 프린터 선택 → "용지 감지" → "테스트 1장".

## 확인되지 않은 부분 (실기기 시험 필요)
- XP-DT427B 가 TSPL 을 지원하는지 (자체 테스트지의 언어 항목 확인). EPL/ZPL 만이면 명령 생성부(`public/tspl.js`)를 바꿔야 한다.
- 비트맵 비트 의미(0=검정)와 출력 방향. 반전되면 설정의 "글자 흑백 반전", "180도"로 맞춘다.
- 라벨 위치 미세 조정(위/왼쪽 여백)이 필요할 수 있다 — 시험 출력 사진을 주면 `labelLayout` 값을 조정한다.

## 개발 메모
- `public/tspl.js` : 명령 생성(순수 함수, `tests/tspl.test.js`). `code128Modules` 는 서버의 `code128Bits` 길이와 같은지 테스트한다.
- `src/lib/barcodes.js` : Code 128 인코더 (독립 디코더 zxing 으로 읽힘 확인), 라벨 미리보기 SVG.
- `public/print-agent/agent.mjs` : 중계 서버 (`tests/agent.test.js`). 윈도우는 PowerShell 로 `winspool.drv` RAW 전송.
- CSP 의 `connect-src` 에 `http://127.0.0.1:9101` 만 추가되어 있다.
