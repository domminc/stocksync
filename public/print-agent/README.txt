StockSync 라벨 출력 프로그램 설치 안내 (매장 PC · 윈도우)
=====================================================

이 프로그램은 매장 PC에서 조용히 실행되면서, StockSync 사이트의 "프린터로 출력" 버튼이 보낸
라벨 명령을 XP-DT427B 프린터로 전달합니다. 처음 한 번만 설치하면 됩니다.

[준비]
 1) 프린터를 PC에 USB로 연결하고, 프린터 드라이버(제조사 제공)를 설치합니다.
    - 윈도우 "프린터 및 스캐너"에 프린터가 보이면 준비 완료입니다.
 2) 용지: 50x30mm 감열 라벨(라벨 사이가 투명한 갭 방식)을 넣습니다.

[설치]
 1) StockSync 라벨 화면의 "출력 프로그램 설치 파일" 링크로 install-windows.bat 을 받아 두 번 클릭합니다.
 2) Node.js 가 없으면 자동 설치를 시도합니다. 설치가 끝나면 창을 닫고 install-windows.bat 을 한 번 더 실행하세요.
 3) "Done" 이 나오면 끝입니다. 이후 윈도우를 켤 때마다 자동으로 실행됩니다 (창이 뜨지 않습니다).

[사용]
 1) 크롬 또는 엣지로 StockSync 라벨 화면을 엽니다. 오른쪽 위에 "연결됨" 이 보여야 합니다.
 2) 맨 아래 "프린터 설정"에서 "설치된 프린터 불러오기"를 눌러 프린터를 고르고, 라벨 사이 간격은 2mm 로 둡니다.
 3) "용지 감지"를 한 번 누르고(라벨이 몇 장 밀려 나온 뒤 멈춤), "테스트 1장"으로 위치를 확인한 뒤 출력합니다.

[문제 해결 — 먼저 "연결 진단" 버튼]
 라벨 화면의 "프린터로 바로 출력" 패널에서 "연결 진단"을 누르면 어디서 막혔는지 알려 줍니다.

 A) "출력 프로그램에 닿지 않습니다"
    - 프린터가 연결된 그 매장 PC에서 열었는지 확인하세요 (폰·다른 PC에서는 안 됩니다).
    - 그 PC의 크롬 주소창에 http://127.0.0.1:9101 을 입력하세요. "실행 중입니다"가 보이면 프로그램은 정상입니다.
      안 보이면 %USERPROFILE%\StockSyncPrint\start-visible.bat 을 실행해 나오는 오류 문구를 알려 주세요.
      (폴더가 없으면 설치가 안 된 것이니 install-windows.bat 을 다시 실행하세요.)
    - 크롬/엣지가 "로컬 네트워크 접근"을 물으면 "허용"을 누르세요. 이미 막았다면 주소창 왼쪽 자물쇠 → 사이트 설정에서 허용으로 바꿉니다.
    - 사파리 등 다른 브라우저는 막을 수 있으니 크롬 또는 엣지를 쓰세요.
 B) "이 사이트의 요청을 허용하지 않습니다"
    - 프로그램이 예전 버전입니다. 사이트에서 설치 파일을 다시 받아 실행하세요.
    - 사이트 주소가 https://jejubaseball.com 인지 확인하세요 (다른 주소로 접속하면 허용되지 않습니다).
 C) "PC의 프린터 목록에 없습니다"
    - 프린터 전원과 USB 케이블을 확인하고, 윈도우 설정 → 프린터 및 스캐너에 프린터가 있는지 보세요. 없으면 제조사 드라이버를 설치합니다.
    - "프린터 설정"의 "설치된 프린터 불러오기"로 이름을 다시 고르세요.
 D) 연결은 정상인데 안 나옴
    - 용지가 라벨 방향/센서 위치에 맞게 들어갔는지, 덮개가 닫혔는지 확인하고 "용지 감지"를 먼저 한 번 누르세요.
    - 프린터 자체 테스트지(전원을 켤 때 FEED 버튼 길게)의 언어 항목이 TSPL 인지 확인하세요.
 E) 글자가 반전/거꾸로/위치가 어긋남
    - 설정의 "글자 흑백 반전", "출력 방향 180도 돌리기"를 바꿔 보고 "용지 감지"를 다시 하세요.
 - 네트워크 프린터(LAN)를 쓰면 연결 방식을 "네트워크 IP"로 바꾸고 프린터 IP 를 입력하세요 (포트 9100).

[제거]
 - %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\StockSyncPrint.vbs 와 %USERPROFILE%\StockSyncPrint 폴더를 삭제하세요.

[참고] 이 프로그램은 이 PC 안(127.0.0.1)에서만 열리고, https://jejubaseball.com 에서 오는 요청만 받습니다.
